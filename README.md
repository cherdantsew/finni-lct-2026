# Финни

Игра для детей 7–11 лет о личном бюджете. Ребёнок заботится о питомце, планирует покупки и копит на свои цели.

Команда **#этовсёии**, ЛЦТ 2026. Для промежуточной сдачи подготовили интерактивный прототип в Figma.

В прототипе работают выбор питомца, недельный план, покупки, рюкзак, кормление и купание, копилка, задания, итоги недели и рост питомца. Подготовлены 9 образов, 15 заданий по трём темам, 8 товаров, 3 цели и 5 игровых недель. Три ключевых экрана показаны на слайде 7 презентации.

## Стек и запуск

Прототип открывается по ссылке в браузере. Интерфейс и переходы сделаны в Figma, модель правил — на JavaScript. Для Android выбраны Kotlin, Jetpack Compose, Room и DataStore. Сервер для основной игры не нужен.

Исходники модели и заданий лежат в `source/`. Проверки запускаются через Node.js без установки дополнительных пакетов:

```sh
node source/test-learning-path.cjs
```
